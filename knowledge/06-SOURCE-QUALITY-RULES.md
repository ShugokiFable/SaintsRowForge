# Source Quality Rules for the AI

Use this priority when sources disagree:

1. Real installed-game file/runtime evidence + Forge round-trip tests
2. Volition-authored public material (Kinzie/Zinyak SDK repos)
3. Reference source implementations with clear provenance (ThomasJepp, SRZoneTools, Gibbed)
4. SaintsRowMods staff/sticky tutorials and current file-search database
5. Well-documented community projects/tutorials
6. Random posts/videos only as leads

Always record game edition/build when a claim is edition-sensitive:
- SRTT legacy
- SRTT Remastered
- SRIV legacy
- SRIV Re-Elected

Never merge assumptions across those buckets without evidence.
